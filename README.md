# Jaque Mate

Tienda estática de objetos de ajedrez, inspirada en la composición editorial de tiendas de autor.

## Ejecutar

Abre `index.html` directamente en el navegador. Es la página de inicio informativa. La sección de productos está separada en `tienda.html`. No necesita instalación ni servidor.

## Incluye

- Diseño responsive para escritorio y móvil.
- Catálogo con filtros por categoría.
- Búsqueda instantánea.
- Lista de pedido lateral con total estimado y eliminación de productos.
- Botón para enviar el pedido armado a WhatsApp.
- Tipografías y recursos visuales cargados desde Google Fonts.

## Configurar WhatsApp

Reemplaza `5491100000000` en `script.js` y en el enlace de contacto de `index.html` por el número real del negocio, incluyendo código de país y sin espacios, signos ni guiones. La página no procesa pagos: el pedido se coordina por WhatsApp.
